# Component Map

The components are related, but they are not interchangeable.

## CCE

**Question:** What does this participant need to know right now?

CCE owns context quality.

It handles relevance, authority, provenance, freshness, duplication, contradiction, supersession, and task-specific packaging.

## Promptitect

**Question:** What is the smallest reliable way to accomplish the objective?

Promptitect owns execution architecture.

It decides whether the job belongs to deterministic software, one model, several workers, tools, reusable skills, bounded judgment, deeper reasoning, or some hybrid.

## Evaluator

**Question:** Does the completed result actually satisfy the requirement?

Evaluator owns independent result judgment.

It verifies evidence instead of trusting implementation claims.

## Tribunal

**Question:** Does this important idea survive serious opposition before we commit to it?

Tribunal owns adversarial decision review.

It separates prosecution, defense, and judgment so the same reasoning process is not quietly allowed to invent both the argument and the verdict.

## Rebrain

**Question:** Can the reasoning process itself be deliberately composed?

Rebrain is experimental.

Its target is not a model that imitates a person. The target is a composite cognitive process that combines selected human reasoning operators with the base model's own strengths while preserving the ability to disagree and self-correct.

## Workers

Workers execute bounded tasks.

A role is not automatically a separate model process. Multiple roles may be implemented by one process when independence is unnecessary, while one role may require multiple independent passes when the stakes justify it.

## Human authority

The method does not treat autonomy as the goal.

Human judgment remains authoritative for taste, irreversible actions, consequential trade-offs, permissions, and anything the system cannot verify well enough on its own.
